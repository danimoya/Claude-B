# CB-03 — private Telegram authorization

Sprinter: `c58a5e06e1b9`. Associated GitHub issue: none.

Enrollment requires an owner-managed `TELEGRAM_ALLOWED_CHAT_IDS` entry or a
single-use owner-issued challenge. Every command, prompt, voice message and
callback requires a paired positive private chat and the same human sender as
the chat. A configured allow-list is enforced again on each action, including
for previously paired chats. Groups, bot senders and forged callback actors are
rejected. Existing owner-paired private chats remain usable when the allow-list
is unset.

Interactive setup uses an unpredictable, three-minute `/start` challenge. It
fences old updates before displaying the challenge, requires a fresh matching
private sender, and bounds polling and response reads by one abort deadline.
A conflicting poller stops enrollment explicitly. The running bot can create a
challenge through owner IPC and `cb --telegram-pair [sender-id]`, without starting
a second poller. Only the nonce digest is persisted; optional sender binding,
expiry, freshness and single-use consumption are checked before enrollment.
Consumption and enrollment are persisted together before success is acknowledged.
Manual allow-list enrollment remains available.

Pending voice input belongs to its originating chat. Confirmation/edit routing
uses chat and message IDs together. Durable submission intent and idempotency
receipts prevent repeated confirmations from submitting ambiguous work again;
interrupted submissions remain visible as uncertain until receipt reconciliation
can establish their result. This recovery contract is implemented with CB-08.

Tests cover private actors, all authorized action paths, replay, expiry, old
updates, sender binding, conflicting pollers, concurrent confirmations and
isolated restart state. Telegram transports and polling are fake; no external
message was sent. A dedicated authorized bot with one polling owner remains the
live end-to-end acceptance gate. No production configuration or running daemon
was changed or restarted.
